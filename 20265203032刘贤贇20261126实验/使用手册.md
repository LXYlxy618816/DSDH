## 一、打开方式

1. 双击 `期刊六圈层_空间分布.html`，用 **Chrome / Edge** 打开。
2. 页面是**单文件离线页面**：地图边界、期刊数据、脚本全部内嵌，不依赖服务器，也不依赖外部地图服务。
3. 页面中的“期刊官网 / 检索”链接需要联网才能跳转；不点击链接时，断网也能正常查看全部图表。
4. 建议窗口宽度不小于 1366 px；窗口变窄时，右侧栏会移到地图下方，分析卡会自动改为单列。

## 三、地图控件

### 3.1 三个图层开关

| 控件    | 选项    | 作用                          | 注意                        |
| ----- | ----- | --------------------------- | ------------------------- |
| **面** | 省域期刊数 | 按各省期刊数做分级设色，颜色越深数量越多        | 北京 264 种，颜色最深             |
|       | 大区    | 按华北、东北、华东、华中、华南、西南、西北七大片区分色 | 用于看“区域块”而不是单省             |
|       | 核密度   | 用高斯核密度显示点的连续密集区             | 需要配合“带宽”滑块；热区被裁剪在中国陆域内    |
|       | 关闭    | 只保留省界                       | 适合单独看点或线                  |
| **线** | 省际重叠  | 两省在 23 个学科门类上的“结构重叠”        | 线宽 = 重叠量；**不是**合作、引用或期刊流动 |
|       | 关闭    | 隐藏线                         | 减少视觉干扰                    |
| **点** | 期刊    | 每本期刊一个点，按级别决定大小与颜色          | 默认；北京点最密                  |
|       | 省域汇总  | 每省一个气泡，气泡大小 = 该省期刊数         | 适合看总量，不适合看单本              |
|       | 关闭    | 隐藏点                         | 只看面或线                     |

### 3.2 筛选

| 控件     | 选项                                                           | 影响范围                               |
| ------ | ------------------------------------------------------------ | ---------------------------------- |
| **级别** | 全部 606 种 / 顶级+权威 25 / 一类 79 / 二类 222 / 三类 280 / 北大差集 53（可定位） | 地图点、省域填色、核密度、重心椭圆、右侧“空间概览/排行/主要重叠” |
| **学科** | 全部学科 + 23 个学科门类                                              | 同上；选某一学科后，地图只保留该学科期刊，省域排行也变成该学科口径  |
| **带宽** | 20–110，默认 42                                                 | 仅在“面 = 核密度”时可用；数值越大，热区越平滑、范围越大     |
| **省名** | 勾选 / 取消                                                      | 勾选时显示期刊数前 12 的省名与数量；选中省份会额外显示      |
| **重心** | 勾选 / 取消                                                      | 显示当前视图的期刊加权重心与 1σ 标准差椭圆            |

> 说明：级别、学科筛选只改变**地图与右侧栏**；下方“集中度 / Moran / 学科×省域矩阵 / 地理编码”四张分析卡固定使用**全样本 606 种**，便于对照，不会随筛选跳动。

### 3.3 按钮

| 按钮         | 作用                                                 |
| ---------- | -------------------------------------------------- |
| **重置**     | 恢复默认：面=省域期刊数、线=省际重叠、点=期刊、级别=全部、学科=全部、带宽=42、省名与重心打开 |
| **导出 PNG** | 把当前地图导出为 2 倍分辨率 PNG（约 2360×1680），不包含右侧栏与页面文字       |

## 五、推荐阅读路径

1. **先看总量与集中度**：默认视图下看北京、上海、江苏、湖北四个深色省域，再看右侧“省域规模”和“集中度”卡。
2. **再看区域结构**：把“面”切到“大区”，观察华北（尤其是北京）与华东的块状差异。
3. **再看连续密度**：把“面”切到“核密度”，拖动“带宽”，观察热区是“单点”还是“连片”。
4. **再看学科结构**：在“学科”中选择“经济学 / 教育学 / 图情”等，观察该学科的省域重心是否仍在北方。
5. **最后看数据可信度**：把“级别”切到“北大差集 53”，对照“范围与地理编码”卡，理解 230 种未定位期刊为什么不能直接上图。
6. **需要写报告时**：直接引用“伦理坐标与局限”和“方法与公式”两栏的口径，避免把示意点误写成编辑部地址。

## 六、指标口径

| 指标            | 页面位置           | 含义                             | 读法                               |
| ------------- | -------------- | ------------------------------ | -------------------------------- |
| **CR4**       | 页头、集中度卡        | 前四省期刊数占全部 606 种的比例             | 63.2%，说明前四省集中了约三分之二              |
| **HHI**       | 集中度卡           | 各省份额平方和                        | 0.211；均分情形约 1/31≈0.032，越高越集中     |
| **Gini**      | 集中度卡           | 省际不均衡程度                        | 0.667，接近“高度集中”                   |
| **Moran's I** | 空间自相关卡         | 省域期刊数（log1p）在 900 km 邻域内的空间自相关 | 0.015，接近 0；没有连片集聚，高值省多为“孤岛”      |
| **1σ 椭圆**     | 地图             | 当前视图期刊点的标准差椭圆                  | 椭圆越小，空间越集中；旋转方向表示主扩散轴            |
| **省际重叠**      | 地图线、右侧“主要省际重叠” | Σ 各学科两省期刊数的最小值                 | 56 表示北京与上海在 23 个门类上的结构重叠量；不是合作次数 |
| **核密度**       | 核密度面           | 高斯核在 16 px 栅格上的叠加              | 带宽越大越平滑；只用于相对密度，不是绝对数量           |

## 八、常见问题

**1. 打开后地图空白或排版错乱？**\
请使用较新的 Chrome / Edge；把浏览器缩放恢复到 100%；不要用 IE。页面不需要联网，但首次打开大文件可能需要一两秒。

**2. 为什么省名只显示十几个？**\
为了避免与密集点位重叠，默认只标注期刊数前 12 的省份；其余省份可以悬停或点击查看。勾选/取消“省名”可以开关。

**3. 为什么筛选后下方分析卡没变？**\
这是刻意设计：级别/学科筛选只影响地图与右侧栏；集中度、Moran、矩阵、地理编码卡固定使用全样本 606 种，保证对照口径稳定。

**4. 为什么“北大差集 53”比 283 少很多？**\
差集条目只有刊名，没有 CN 号；只有 53 种能从刊名中的省 / 市 / 高校 / 别称推断出出版地，其余 230 种属于“资料缺席”。地图不会用虚构坐标补点。

**5. 为什么北京的点挤成一团？**\
北京有 264 种，占 43.6%，点层按真实数量落点，密集是数据本身的结构。可以切换“点 = 省域汇总”看更干净的总量气泡。

**6. 导出 PNG 没反应？**\
浏览器可能拦截了下载，请允许本站下载；导出为 2 倍分辨率，文件较大时需等待一两秒。

**7. 为什么“境外”是 0？**\
本目录只收中国大陆中文期刊，境外与港澳台不在收录范围内。这是“范围性缺席”，不能据此推断中国人文社科期刊只在国内出版。

**8. 地图上的点和真实编辑部位置不一致？**\
点位是省内示意采样，不是地理编码到门牌地址；具体出版地以 CN 号前两位判定的省级行政区为准。
