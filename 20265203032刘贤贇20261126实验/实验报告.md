## 摘要

本实验把“人文社科期刊六圈层知识图谱”从学科—级别的关系结构，转换为可读的中国省域空间分布。606 种苏州大学目录期刊以 CN 号前两位地理编码到 31 个省级单元，形成**点**（期刊）、**线**（省际学科结构重叠）、**面**（省域 / 大区 / 核密度）三层；并计算集中度、Moran's I、学科×省域矩阵与地理编码覆盖率。结果显示：期刊出版地高度集中于北京（264 种，43.6%），CR4=63.2%、HHI=0.211、Gini=0.667；但 Moran's I≈0.015，省域期刊数没有形成连片集聚，呈现“**单点虹吸**”而非“区域带”。同时，苏大目录 606 种全部可定位，北大核心差集 283 种中仅 53 种能由刊名推断出版地，230 种属于“资料缺席”，说明**地理编码的标识质量直接决定空间分析的可信度**。

***

## 一、实验目的

1. 把第 6 章的关系网络（节点、边、学科、级别）转成第 7 章要求的空间对象（点、线、面）。
2. 掌握省级地理编码、Albers 投影、核密度、空间自相关等基本空间人文方法。
3. 用集中度与空间自相关回答两个问题：期刊出版地**有多集中**？这种集中是**连片集聚**还是**单点虹吸**？
4. 记录地理编码的来源、级别与缺席，练习对“地图上的空白”的解释，而不是用虚构坐标填补。
5. 形成一个可离线打开、可交互、可导出的单文件作业页面，并配套使用手册。

### 2.3 数据质量问题（预处理时记录）

1. **字段名与内容不一致**：原数据把 CN 号放在 `issn` 字段中。CN 号前两位是**出版地行政编码**，ISSN 则是国际刊号，两者含义不同；本实验按 CN 号处理，并在页面中明确标注。
2. **CN 10 序列**：18 种期刊使用 `10-` 前缀，按“中央在京序列”计为北京，可信度降为 B。
3. **无连字符**：2 种报纸理论版（如人民日报理论版、光明日报理论版）的 CN 号为 6 位数字，无连字符，按前两位 11 计为北京，可信度 B；严格口径下它们不是“期刊”，本页按原目录保留并计入 606。
4. **差集缺标识**：283 种差集条目没有 CN 号，只能靠刊名中的省 / 市 / 高校 / 地理别称推断；推断不出的 230 种不进入地图。

## 三、方法

### 3.1 地理编码：CN 号 → 省级行政区

对每条苏大目录期刊取 CN 号前两位，按国家标准省级代码映射：

```
geo(j) = CN[ int( cn_code(j)[0:2] ) ]
CN = {11:北京, 12:天津, 13:河北, 14:山西, 15:内蒙古, 21:辽宁, 22:吉林, 23:黑龙江,
      31:上海, 32:江苏, 33:浙江, 34:安徽, 35:福建, 36:江西, 37:山东,
      41:河南, 42:湖北, 43:湖南, 44:广东, 45:广西, 46:海南,
      50:重庆, 51:四川, 52:贵州, 53:云南, 54:西藏,
      61:陕西, 62:甘肃, 63:青海, 64:宁夏, 65:新疆}
```

可信度分级：

| 级别 | 依据                  | 数量  |
| -- | ------------------- | --- |
| A  | CN 号前两位（官方行政编码）     | 586 |
| B  | CN 10 中央在京序列 / 无连字符 | 20  |
| B  | 差集刊名中的省、市、高校、地理别称   | 53  |
| C  | 差集刊名无行政区线索（未定位）     | 230 |

> 说明：C 级不是“不存在”，而是“现有字段不足以定位”，属于 ch07 所说的**资料缺席**。地图不为其补点。

### 3.2 投影与点位

- **投影**：Albers 等积圆锥投影，中央经线 105°E，标准纬线 25°N / 47°N，原点 35°N；输出 viewBox 1180×840。
- **不用 Web Mercator**：避免高纬地区面积被放大，保证省域面积比较不失真。
- **省内点位**：在省域主多边形内做网格抖动采样（网格间距按点数自适应），点只表示“该省有这么多本”，**不是编辑部地址**。北京 264 种因此形成高密度点团，这是数据本身的结构。

### 3.3 点 / 线 / 面

| 空间对象  | 页面表达                      | 语义                       |
| ----- | ------------------------- | ------------------------ |
| **点** | 期刊点；颜色与大小 = 级别；空心点 = 北大差集 | 一本期刊一个点                  |
| **线** | 省际学科结构重叠；线宽 = 重叠量         | 两省在 23 个门类上的结构相似，不是合作/引用 |
| **面** | 省域期刊数 / 七大区 / 核密度         | 省域总量、区域块、连续密度            |

省际重叠度：

```
Overlap(a,b) = Σ_d min( n_a,d , n_b,d )
```

其中 `n_a,d` 为省 a 在学科 d 的期刊数；只保留重叠量较大、且两省规模均不小于 3 的前 48 条线，避免单刊省份产生大量伪边。

### 3.4 空间统计

**集中度**：

```
CR4 = Σ(i=1..4) s_i
HHI = Σ s_i²
Gini = Σ(2i − n − 1)·x_i / (n²·x̄)
```

**全局 Moran's I**（900 km 距离带、行标准化权重、`x = log(1+期刊数)`）：

```
I = (n / ΣΣw_ij) · Σ_i Σ_j w_ij (x_i − x̄)(x_j − x̄) / Σ_i (x_i − x̄)²
```

**核密度**（16 px 栅格，高斯核，带宽 h 可调）：

```
KDE(x) = Σ_i exp( −‖x − x_i‖² / 2h² )
```

**重心与 1σ 椭圆**：对当前视图所有点的 x、y 求均值与协方差矩阵，取特征值/特征向量得到椭圆长短轴与旋转角。

> 本实验的 Moran's I 只做**描述性判读**，未做随机置换显著性检验；因此表述为“接近 0”，不写“显著/不显著”。

## 四、实验步骤

1. **解析源数据**：从 `journal-six-rings.html` 读取 `graph-data`，分离苏大目录 606 种与北大核心差集 283 种；读取 `official-urls`。
2. **CN 号地理编码**：提取前两位，映射省级行政区；标记 CN 10、无连字符等异常为 B 级。
3. **差集名称地理编码**：用省级地名、城市名、高校名与地理别称（江汉、湖湘、江淮、齐鲁、中州、燕赵、岭南、巴蜀等）匹配，得到 53 个 B 级点；其余 230 个记为 C 级。
4. **底图处理**：读取 DataV 省级边界，简化后做 Albers 投影，生成 1180×840 的地图坐标；海南离岛与南海诸岛单独处理。
5. **点位生成**：按各省期刊数，在省域多边形内做网格抖动采样；苏大目录点优先落位，差集点随后落位。
6. **前端渲染**：用单文件 HTML + SVG + 原生 JavaScript 绘制面、线、点、标签、图例、南海缩略图、比例尺与投影说明。
7. **统计与图表**：计算 CR4/HHI/Gini、Lorenz 曲线、Moran 散点与 I、学科×省域矩阵、重心与 1σ 椭圆、地理编码表。
8. **质量检查**：用 Edge headless 截图检查默认、核密度、大区、省域汇总、差集、学科筛选、省份选中、期刊选中八种状态；用 DOM 导出检查节点数、边数、标签数与统计值；确认无 JavaScript 运行时错误。

## 五、结果与分析

### 5.1 总体：高度集中的单中心结构

| 排名 | 省级单元 | 期刊数 | 占比    |
| -- | ---- | --- | ----- |
| 1  | 北京   | 264 | 43.6% |
| 2  | 上海   | 56  | 9.2%  |
| 3  | 江苏   | 32  | 5.3%  |
| 4  | 湖北   | 31  | 5.1%  |
| 5  | 广东   | 23  | 3.8%  |
| 6  | 吉林   | 18  | 3.0%  |
| 7  | 湖南   | 17  | 2.8%  |
| 8  | 四川   | 16  | 2.6%  |
| 9  | 陕西   | 16  | 2.6%  |
| 10 | 山东   | 14  | 2.3%  |

- **CR4 = 63.2%**：前四省集中了约三分之二的期刊。
- **HHI = 0.211**：远高于 31 省均分情形（约 0.032）。
- **Gini = 0.667**：省际分布高度不均衡。
- 洛伦兹曲线明显偏离对角线，说明这不是“略有差异”，而是结构性集中。

### 5.2 大区：华北的高占比主要由北京单点贡献

| 大区 | 期刊数 | 占比    |
| -- | --- | ----- |
| 华北 | 286 | 47.2% |
| 华东 | 135 | 22.3% |
| 华中 | 56  | 9.2%  |
| 东北 | 36  | 5.9%  |
| 西北 | 32  | 5.3%  |
| 华南 | 31  | 5.1%  |
| 西南 | 30  | 5.0%  |

华北的 286 种中，北京占 264 种；去掉北京后，华北仅 22 种。因此“华北第一”并不是区域整体发达，而是**首都单点**造成的区域统计幻象。这是 ch07 强调的尺度效应（MAUP）：同一批数据，按省看与按大区看会得到不同的“区域故事”。

### 5.3 空间自相关：集中但不连片

- 全局 **Moran's I ≈ 0.015**，接近 0。
- 散点图中，北京、上海、湖北位于 **HL 象限**（自身高、邻域低）；西部省份多为 **LL**；HH 象限很少。
- 解释：省域期刊数没有形成连续的高值带，高值省更像“孤岛”。因此本实验把这种结构概括为“**单点虹吸**”，而不是“长三角/京津冀连片集聚”。

需要强调：I 接近 0 不等于“没有集中”；集中度指标（CR4/HHI/Gini）已经很高。两者并不矛盾——**集中可以发生在单点，而不发生在连片区域**。

### 5.4 学科 × 省域矩阵：北京是全门类，其他省是“综合 + 特色”

- 北京行几乎整行最深：经济学 34、政治学 22、综合性社会科学 20、艺术学 20、历史学 17，说明它的优势不是某一学科，而是**全门类**。
- 上海：综合性社会科学 9、语言学 5、经济学 5、教育学 5。
- 江苏：综合性社会科学 11、经济学 4、语言学 3、教育学 3。
- 湖北：综合性社会科学 8、教育学 4、管理学 3。
- 吉林：综合性社会科学 3、图书馆情报与文献学 3，在图情门类有相对集中。
- 广东：综合性社会科学 8、经济学 5。

矩阵把原图谱“学科—期刊”的二部关系，折叠成“学科—省域”的二部关系，是六圈层网络落到地理后的结构摘要。

### 5.5 省际重叠网络：北京是绝对枢纽

重叠量前五的省对：

| 省对      | 重叠量 |
| ------- | --- |
| 北京 ↔ 上海 | 56  |
| 北京 ↔ 江苏 | 32  |
| 北京 ↔ 湖北 | 31  |
| 上海 ↔ 江苏 | 29  |
| 上海 ↔ 湖北 | 27  |

网络中北京几乎与所有省份相连，上海—江苏—湖北形成次级三角。该网络表示“学科结构相近”，**不表示合作、引用或期刊流动**；线越粗只说明两省在 23 个门类上的期刊配置越相似。

### 5.6 地理编码：标识质量决定地图可信度

| 来源           | 数量  | 级别 | 说明                |
| ------------ | --- | -- | ----------------- |
| CN 号前两位      | 586 | A  | 官方行政编码，直接判省       |
| CN 10 / 无连字符 | 20  | B  | 中央在京序列或格式异常       |
| 差集刊名推断       | 53  | B  | 省 / 市 / 高校 / 地理别称 |
| 差集无线索        | 230 | C  | 未定位，不进入地图         |

- 苏大目录：**606 / 606 = 100%** 可定位。
- 北大核心差集：**53 / 283 = 18.7%** 可定位。
- 同样是“期刊目录”，有没有 CN 号，决定了它能不能被稳定地放上地图。这是本实验最重要的数据质量发现之一。

### 5.7 国内外范围：0 境外是“范围性缺席”

目录只收中国大陆中文期刊，境外与港澳台为 0。页面用“境内 606 / 境外 0”的显式条带和“范围性缺席”说明来处理，而不是把 0 当成“全球只有中国有期刊”。这对应 ch07 对“边界”和“缺席”的讨论：**地图上的空白，有时是资料范围造成的，不是事实本身。**

## 七、讨论与局限

1. **出版地 ≠ 知识生产地**：CN 号登记的是出版单位所在地。作者、议题、引用网络可能完全在别处。地图回答的是“刊物登记在哪里”，不是“知识发生在哪里”。
2. **点位是示意，不是地址**：省内点按多边形采样展开，只表示“同省有多本”；省内差异被抹平（MAUP），不能用于判断编辑部具体位置。
3. **级别是制度产物**：苏大目录的“一类权威 / 二类 / 三类”与北大核心是两套不同用途、不同年份的评价体系；级别不等于质量，也不等于引用影响。
4. **差集覆盖不足**：283 种差集中只有 53 种可定位，230 种未上图。切换到“北大差集 53”时显示的 53 个空心点不能代表全部 283 种；未定位是资料缺席，不是不存在。
5. **范围性缺席**：境外与港澳台为 0，是目录范围限制；不能据此推断中国人文社科期刊只在国内出版。
6. **统计口径**：Moran's I 未做随机置换检验，仅作描述性判读；核密度带宽是分析者选择，默认 42 px，改变带宽会改变热区形态；省际重叠是“结构相似”，不是合作/引用。
7. **数据质量**：原数据 `issn` 字段实为 CN 号；含 2 个报纸理论版条目；CN 10 序列按中央在京处理。这些都在页面“方法与公式”和本报告中披露。
8. **伦理**：期刊为公开出版物，不涉及个人隐私；但页面不应被用于机构考核、期刊排名或个人评价。级别与地图位置都不构成质量判断。

## 八、结论

1. 把六圈层期刊图谱空间化后，可以看到一个**高度集中但空间上不连片**的结构：北京 43.6%、CR4 63.2%、Gini 0.667，而 Moran's I≈0.015。
2. “集中”主要来自**单点虹吸**，不是区域带；按大区看会被北京放大，按省看更接近真实结构。
3. **地理编码质量决定空间分析的可信度**：CN 号让苏大目录 100% 可定位；只有刊名的差集仅 18.7% 可定位，230 种必须作为“缺席”处理。
4. 点、线、面三层与集中度/ Moran / 矩阵/ 覆盖率四类证据可以互相校验；页面与手册把口径、来源、局限写清楚，避免“地图看起来很专业，但结论过度”的常见问题。
